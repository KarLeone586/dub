# Колесо фортуны — исходники

## Файлы
- index.html — адаптивное колесо для Telegram Mini App.
- bot/bot.mjs — Telegram-бот: приветствие, приём фото/PDF чеков, панель администратора /admin.
- bot/server.ts — Bun HTTP-сервер: проверка Telegram initData, розыгрыш, баланс попыток, чеки, очередь сообщений.
- bot/config.example.json — настройки бота без секретов.
- build-server.mjs — обновляет встроенный HTML сервера после изменения index.html.

## Запуск сервера
Требуется Bun. Задайте переменные окружения BOT_TOKEN и PORT (например, 3000). DB_PATH — путь к постоянной SQLite-базе; по умолчанию /data/wheel.sqlite. Директория базы должна существовать. Для контейнера обязательно подключите постоянный том /data. Запуск: bun bot/server.ts. Используйте один экземпляр сервера с этой базой. Сервер размещается по публичному HTTPS-адресу.

После изменения index.html выполните node build-server.mjs и перезапустите/опубликуйте server.ts. При переносе на другой домен измените APP_URL в server.ts и miniAppUrl в config.json.

## Запуск бота
Требуется Node.js 20 или новее. Скопируйте bot/config.example.json в bot/config.json, вставьте токен и HTTPS-адрес сайта. Запуск: node bot/bot.mjs. Токен в исходники и репозиторий не добавлять. Одновременно должен работать только один polling-процесс бота; webhook должен быть отключён.

## Администратор и чеки
Администратор: 7545540622. ID проверяется и в боте, и на сервере. Чтобы поменять его, обновите ADMIN_ID в bot.mjs и server.ts.
Администратор должен открыть @Dubrovka86_bot и нажать Старт, иначе Telegram не разрешит доставлять ему чеки. /admin показывает до 10 ожидающих чеков.
Пользователь отправляет фото или PDF (до 10 МБ). Чек хранится как Telegram file_id/file_unique_id, сам файл сервер не скачивает. Администратор вручную проверяет сумму от 5000 рублей, реквизиты и отсутствие повторного использования, затем нажимает Одобрить или Отклонить.
Одобрение атомарно начисляет один прокрут. Повторное нажатие не начисляет ещё один. Одновременно у пользователя может быть один ожидающий чек. Повторный Telegram file_unique_id отклоняется. Другой снимок того же бумажного чека может иметь новый ID: его должен выявить администратор. OCR и проверка ФНС не реализованы.

## Розыгрыш и сообщения
Первый прокрут бесплатный. Каждый прокрут списывает одну попытку на сервере. Результат и попытки привязаны к Telegram ID. Очистка браузера их не сбрасывает. История прежней серверной версии мигрируется без выдачи новой бесплатной попытки.
Выигрыши, чеки для администратора и решения по чекам отправляются через постоянную очередь. Бот периодически обрабатывает очередь между запросами Telegram. Поэтому процесс бота должен работать постоянно. После сбоя отправка повторяется. Telegram sendMessage не имеет ключа идемпотентности: при редком сбое между отправкой и подтверждением возможно повторное уведомление, но не повторное начисление попытки.
